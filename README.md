<h3 align="center">CyberMP Types</h3>

✅ **Official** type definitions for CyberMP multiplayer, contains:
- @cybermp/server-types: server environment definitions
- @cybermp/client-types: client environment definitions
- @cybermp/browser-types: browser environment definitions
